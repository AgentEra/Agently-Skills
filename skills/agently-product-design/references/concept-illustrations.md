# 用 Spotkit 辅助概念与产品理念表达

本指导用于判断何时借助抽象产品插图，具体制图规范仍由可用的 `spotkit` 维护。它是[视觉叙事](visual-storytelling.md)的辅助方式，不新增方案、阅读或运行验收流程。

## 先判断图要帮助读者理解什么

表达关系、概念或产品设计理念时，先用一句话写清“谁/什么对象，在什么条件下做什么，发生什么变化，给谁带来什么价值”。只有抽象图能帮助读者辨认这一关系时才使用；装饰图不能代替论证，也不能为直观界面增添无意义插图或副标题。

| 当前问题 | 适合的表达 |
|---|---|
| 想直观说明分组、汇聚、筛选、权限门槛、比较、前后状态或选择 | 可借 Spotkit 探索一个主要关系及少量可辨认对象，保留必要条件的正文说明 |
| 功能介绍、文档中的产品概念、小型功能卡或有意义的空态 | 按项目现有视觉体系判断是否采用同族 SVG 插图；没有用途时保持简洁文本 |
| 必须准确说明系统归属、数量、依赖、角色权限、异常或多步主次流程 | 按[画板指导](diagram-and-board.md)画有明确标签与边界的语义图；必要时另外附概念插图，不能以隐喻替代合同 |
| 用户要求技术架构图 | 仍交付 SVG 逻辑分层图；不降成装饰卡片、Spotkit 功能小图或 Mermaid |
| 要探索完整界面、复杂收纳或视觉风格 | 使用应用模块、组件稿或适用的 imagegen；不强套 Spotkit 的小型插图结构 |

## 只安装概念表达核心

Spotkit 是可选辅助，默认按实际用途选择文件，不把整个上游仓库放入技能目录。概念表达核心保留：

- 入口、规范与许可：`SKILL.md`、`AGENTS.md`、`SPEC.md`、`LICENSE`；精简入口只链接已安装内容。
- 概念与质量参考：`references/metaphor.md`、`archetypes.md`、`theme.md`、`scaling.md`、`sets.md`、`checklist.md`、`icons.md`。
- 绘图资源：`assets/illustration.css`，以及规范列出的十二个独立 `examples/*.svg` 模板；不再保留相同内容的汇总示例手册。
- 检查依赖：`check.py`、`build.py`、`icons.py`。文档检查模式会导入后两者，不因看似重复就删除；不在安装目录运行生成器重建图库。

网站、部署配置、展示图库、样张总览、深浅色重复导出、截图专项及图像模型提示词参考不默认安装。需要额外内容时，只取对应文件放到当前任务工作区；复杂界面和 imagegen 工作继续用各自模块。

本机精简安装以 `spotkit/.profile.json` 记录上游版本、保留文件与本地入口适配，更新时遵守该清单，避免重新恢复全仓库。精简前在技能发现目录之外保留可恢复备份，精简后核对入口引用、独立 SVG 模板及检查器；文档检查通过不等于实际图稿视觉通过。

## 使用已安装的 Spotkit

1. 从当前可用技能中定位并读取 `spotkit/SKILL.md`；仅讨论概念时先按需读隐喻／布局关系，实际生成 SVG 或确定几何规格前再读取 `SPEC.md` 及所选示例与检查规则。不要假定别人装在同一路径，也不把外部 Skill 当作已加载。
2. 先选关系，再选少量图形元素和构图。选择能表达目标的现有布局及 SVG 示例进行适配，避免每次凭空换视觉语言；概念确有歧义时才比较不同语义方向。
3. 同族图保持共同的表面、图标、描边、强调色与层次规则，变化的是所讲关系和构图。先沿项目已有 Token 与图标体系决策，不把 Spotkit 自带配色、尺寸或 Phosphor 家族推广为所有应用组件规范。声称符合其原配规范时按原 `SPEC.md` 核验；项目另有规范时明确为适配方案，不能混用后仍宣称原规范全部通过。
4. 精确几何类插图直接交付可编辑 SVG。Spotkit 的 SVG 方法仅约束这类制品，不禁止其他场景使用 imagegen。提供简短概念说明与真实文件，避免在产品界面堆砌设计理由。
5. 用其 `check.py` 和人工语义判断各自检查，按实际嵌入尺寸读画面，检查深浅主题、必要对象是否被淡出/遮挡，以及多图同页的 ID、遮罩和滤镜是否互相影响。核对宿主的主题传递和导出能力；文件能解析、lint 通过不等于读者理解或宿主已验证。

## 复验与边界

让未参与设计讨论、但具备合理背景的角色，仅凭图与当前正文复述主要关系和变化。再暂时忽略装饰图标/标题，检查位置、连接、分组和状态本身能否支撑图意；精确名称、数字和条件仍就近保留，不把“图中不写字”泛化为所有关系图禁用标签。不能为了套隐喻改写事实、掩盖权限条件或暗示不存在的能力。

沿用现有问题 ID，记录所选关系、适配来源、语义/视觉/宿主检查与未验范围。候选插图不证明方案有效，静态角色审读不是真人理解测试。Spotkit 不可用时，继续用原生 SVG、画板或简图完成已授权工作；说明未采用其专有规范，不自动安装依赖或以缺少辅助 Skill 阻塞整项工作。
